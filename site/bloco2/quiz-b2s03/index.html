    📝 Quiz — Low Code, Flowise, N8N e Monitoramento de IA¶

    Teste seus conhecimentos! Clique na resposta que considerar correta.

    Questão 1

    O que significa o termo Low Code?

    • a. Um protocolo de comunicação entre APIs.
    • b. Uma linguagem de programação voltada para dispositivos móveis.
    • c. Um sistema operacional desenvolvido para servidores.
    • d. Uma abordagem de desenvolvimento que reduz a necessidade de codificação manual, usando interfaces visuais.
    • e. Um banco de dados relacional de código aberto.

    Questão 2

    O que é o Flowise?

    • a. Um serviço de hospedagem de sites estáticos.
    • b. Um sistema de controle de versão de código.
    • c. Um framework de CSS para criação de interfaces.
    • d. Uma plataforma de envio de e-mails em massa.
    • e. Uma ferramenta open source de low code para criar fluxos de IA (LLMs) visualmente.

    Questão 3

    O que é o N8N?

    • a. Um sistema de gerenciamento de containers Docker.
    • b. Uma plataforma open source de automação de fluxos de trabalho que conecta diferentes serviços e APIs.
    • c. Uma IDE para desenvolvimento de aplicações web.
    • d. Um servidor de autenticação baseado em OAuth.
    • e. Um banco de dados NoSQL para armazenar documentos JSON.

    Questão 4

    Qual é o principal benefício das ferramentas Low Code para empresas?

    • a. Tornar as aplicações mais lentas e pesadas.
    • b. Impedir a integração com sistemas legados.
    • c. Substituir completamente os desenvolvedores em qualquer projeto.
    • d. Permitir que pessoas sem conhecimento avançado de programação criem aplicações e automações.
    • e. Aumentar o custo de infraestrutura das empresas.

    Questão 5

    No N8N, como se chama a unidade básica que executa uma ação dentro de um fluxo de trabalho?

    • a. Branch.
    • b. Node (nó).
    • c. Container.
    • d. Module.
    • e. Widget.

    Questão 6

    No Flowise, qual é o tipo de modelo de linguagem frequentemente utilizado nos fluxos?

    • a. DBMS (Database Management System).
    • b. CDN (Content Delivery Network).
    • c. ORM (Object Relational Mapping).
    • d. VPN (Virtual Private Network).
    • e. LLM (Large Language Model).

    Questão 7

    O que é um workflow no contexto de ferramentas Low Code como N8N?

    • a. Uma linguagem de marcação para criar interfaces.
    • b. Uma sequência automatizada de tarefas e ações conectadas para atingir um objetivo.
    • c. Um tipo de banco de dados distribuído.
    • d. Um arquivo de configuração de servidor web.
    • e. Um protocolo de segurança para redes corporativas.

    Questão 8

    Qual das opções abaixo é um exemplo de uso do N8N?

    • a. Compilar código C++ para produção em servidores Linux.
    • b. Criar modelos de machine learning do zero.
    • c. Automatizar o envio de e-mails quando um novo registro é criado em uma planilha do Google Sheets.
    • d. Gerenciar permissões de usuários em sistemas operacionais.
    • e. Renderizar páginas web em 3D no navegador.

    Questão 9

    Qual é o principal objetivo de monitorar um agente de IA em produção?

    • a. Substituir a necessidade de testes unitários no projeto.
    • b. Detectar problemas de qualidade, custo e desempenho antes que afetem os usuários.
    • c. Impedir que o agente responda perguntas fora do escopo.
    • d. Aumentar automaticamente o número de ferramentas disponíveis.
    • e. Reduzir o tamanho do código do agente.

    Questão 10

    Por que é importante monitorar o consumo de tokens de um agente de IA?

    • a. Porque sem monitorar tokens o agente para de funcionar automaticamente.
    • b. Porque cada token consumido representa um custo financeiro, e picos inesperados podem indicar loops ou respostas desnecessariamente longas.
    • c. Porque tokens são arquivos que ocupam espaço no banco de dados.
    • d. Porque o número de tokens define a cor da interface do usuário.
    • e. Porque monitorar tokens é exigido pela LGPD.
