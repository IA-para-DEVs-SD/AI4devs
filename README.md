# AI4Devs — Curso de IA para Desenvolvedores

[![Deploy MkDocs](https://github.com/IA-para-DEVs-SD/AI4devs/actions/workflows/deploy-mkdocs.yml/badge.svg)](https://github.com/IA-para-DEVs-SD/AI4devs/actions/workflows/deploy-mkdocs.yml)

Resumo interativo do curso **IA para Desenvolvedores** — material de apoio com conteúdo teórico, quizzes e labs práticos.

## Conteúdo

### Bloco 1 — Fundamentos
- Fundamentos de IA e LLMs
- Prompt Engineering
- IA no Desenvolvimento de Software

### Bloco 2 — Agentes e Automação
- Tools e ReAct
- Memória e Orquestração
- Low Code e Monitoramento
- MCP e LangGraph
- RAG e Avaliação
- Agentes em Produção

## Desenvolvimento local

```bash
pip install mkdocs-material mkdocs-minify-plugin
mkdocs serve
```

Acesse `http://localhost:8000`.

## Deploy

O deploy é automático via GitHub Actions a cada push na `main`. O site é publicado na branch `gh-pages`.
